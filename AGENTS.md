# OCPNG Repository Guardrails

- This repository is WASDOK 360 for the Ombudsman Commission of Papua New Guinea.
- Do not introduce NJSS FF3/FF4, budget, supplier, commitment or expense-ledger domain code.
- Never commit real credentials, production personal data, Leadership declarations, intelligence, legal-privilege records or real complaint evidence.
- All prototype/UAT records must be fictional and visibly marked DEMO.
- Every new public business table requires RLS in the same migration set.
- Protected access requires permission + scope/assignment + compartment. System Administrator is not a protected-content bypass.
- Preserve Right to be Heard / natural-justice gates and human decision authority.
- Annual Statement variance/anomaly flags are not misconduct findings.
- Prefer tests before workflow/security changes. Run domain, schema, route and static checks before opening a PR.
